## Описание проекта
**«ПсихоПомощь»** — это веб-приложение для онлайн-записи на психологические консультации. 
Проект создан в рамках учебной дисциплины «Разработка web-приложений на основе MVC-фреймворка».

Система позволяет клиентам находить специалистов и записываться на удобное время, а психологам — управлять своим расписанием и назначать консультации в личном кабинете.
